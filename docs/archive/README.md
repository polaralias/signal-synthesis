# Archive

This directory contains historical planning, implementation notes, and older working documents.

Use these files as archaeology, not as current contract.

## How To Treat Archive Docs

- useful for understanding how the repository evolved
- useful for tracing old assumptions and prior plans
- not automatically trustworthy as current behavior
- subordinate to the root `README.md`, `docs/README.md`, `GLOSSARY.md`, and current canonical docs in `docs/`

## What Lives Here

- phase plans
- implementation guides
- old bug lists
- historical product vision notes
- older QA or usage-tracking notes

If a truth in archive docs is still current and important, it should be promoted into the canonical knowledge surface rather than rediscovered from archive later.
